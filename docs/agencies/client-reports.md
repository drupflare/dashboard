Drupflare does not send monthly client reports yet. Not available yet.

For now, build the report from two exports:

- **Usage.** Export each client's monthly views as CSV from the Clients page. Months with no usage records show as not recorded. See [Client workspaces](/docs/guides/teams/client-workspaces).
- **Site state.** Read each site's health and repair history, and note any repairs from the month.

Put both into your own template. Do not present a month as zero when it shows not recorded.

Report emails will be a separate feature. This page changes when they ship.
