Use the same order for every client, so each one ends in the same state.

1. **Create the client workspace.** Add the client at `/org/clients`. See [Client workspaces](/docs/guides/teams/client-workspaces).
2. **Get the sites in.** Ask the client to delegate each site to your organization. See [Delegate to an agency](/docs/guides/teams/delegate-to-an-agency). Accept each batch on the Delegations page.
3. **Group the sites under the client.** Adding a site to a client is not in the dashboard yet. Keep a list of which sites belong to which client until it is.
4. **Give the team access.** Add site grants for the people who work on each site. Use the least role that does the job. See [Site grants](/docs/guides/teams/site-grants).
5. **Record the owners.** Set the technical and business owners on each site, so the next person knows who to call. See [Cost centers and showback](/docs/guides/billing/cost-centers-and-showback).
6. **Check the first run.** Read the site's health page and the restore points (the moments a site can be restored to). See [Health tree](/docs/guides/monitoring/health-tree).

Write the client's name, sites and owners in the onboarding record before you close it.
