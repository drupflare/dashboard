A template is the starting code for a new site. Use a template for each common site type your agency builds.

## What exists today

- Drupflare's own templates, which new sites start from. See [Create a Drupal site](/docs/guides/sites/create-a-drupal-site).
- A custom Worker site built from your own bundle. See [Create a custom Worker site](/docs/guides/sites/create-a-custom-worker-site) and [Bring your own template](/docs/guides/sites/bring-your-own-template).
- A template you make for the dashboard to manage. See [Make a template the dashboard can manage](/docs/guides/templates/make-a-template-the-dashboard-can-manage).

## Keeping an agency library

A shared library of agency-only templates is not available yet. Keep the template source in your own repository (the place where your code is stored), and link each new site to the repository it came from.

Review each template before you use it on a client site. Templates carry code that runs on every site made from them.
