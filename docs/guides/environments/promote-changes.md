This page says why copying a change from an environment to the live site is not available yet. It is for site owners who want that step.

Promoting changes from an environment to the live site is not available yet. The dashboard has no route or page that copies a staging or dev environment into the site it was made from.

To change the live site today, make the change on the site itself and keep a record of it. Code changes go through the edit and code history flow. See [roll back code](/docs/guides/code/roll-back-code). Settings changes go through the Config page, and the change history records each one.

An environment is a copy of a backup. Deleting it does not change the original site. See [staging and previews](/docs/guides/environments/staging-and-previews).
