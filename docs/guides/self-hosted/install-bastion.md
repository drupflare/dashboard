This page says what is written about installing Bastion so far. It is for owners who plan to run a node.

Install steps for Bastion (the software a node runs) are not written here yet.

After the bastion runs on the box, pair it with the dashboard. Pairing starts with the bastion pair command on the box, given the address on the box and the claim token the dashboard shows once. See [pair a node](/docs/guides/self-hosted/pair-a-node).
