This page says that major Drupal version upgrades are not run yet. It is for owners planning one.

Drupflare does not run a major Drupal version upgrade yet.

A Drupal 7 through 10 site needs its upgrade before you move it. The import report says which version it found. Upgrade the site on its current server, then check it again. Drupal 11 sites move as they are.

See the [migration overview](/docs/guides/migration/overview) for the sites that move today.
