This page shows you how to rename a site. It is for site owners.

You can rename only a site that a self-hosted box reported to the dashboard. Open the site and choose Rename Site.

The name is 1 to 100 characters after spaces at the ends are removed. Control characters are refused. Another live site in the same organization cannot have the same name.

Every other site keeps its name, because the name is part of its address. The dashboard does not change that address. To use a different address for a managed site, create a new site with the name you want, then delete the old one. See [delete and restore a site](/docs/guides/sites/delete-and-restore).
