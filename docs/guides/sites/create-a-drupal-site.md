This page shows you how to create a managed Drupal site from a template. It is for site owners.

A managed Drupal site is one of the templates on the Create a Site page. The dashboard builds it for you and gives it an address on `drupflare.app`.

## Steps

The wizard has two steps. Each one has a default, so you can skip either.

1. **Template.** Pick the Drupal card. Other cards in the list lead elsewhere: Import opens the import page, and Bring Your Own opens the custom Worker upload. See [create a custom Worker site](/docs/guides/sites/create-a-custom-worker-site) for that path.
2. **Name and Create.** Type a name, then choose Create.

The name becomes the first part of the site's address, so `my-school` gives `my-school.drupflare.app`. A name has 3 to 63 characters. It uses lowercase letters, numbers and single hyphens, and it starts and ends with a letter or number. Two kinds of name are refused. Reserved names return "This name is reserved." Names with a paid-only ending return "Names with this ending are for paid managed sites."

## Progress

Choose Create and the dashboard opens the progress page for the new site. The site is listed once its create finishes.

If the create fails, the wizard shows the error and stays open. Read the message, change what it names, and choose Create again.

## Next steps

- Check the site's readiness and first page before you share the address. See [first-day checklist](/docs/start/first-day-checklist).
- Set the site's options on the Config page. See [managed settings](/docs/guides/sites/managed-settings-and-redirects).
