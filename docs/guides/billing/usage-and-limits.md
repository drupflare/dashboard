This page explains how views are counted and what the limits are. It is for owners who want to know what their organization uses.

Usage is counted per organization and per site. The counted meter is views. The count is a lower bound: it can trail the visits a site receives, so a limit can take effect a little after the number reaches it. The bound is described in [spend budgets](/docs/guides/billing/budgets).

## Where you see usage

The budget screen for an organization and for each site shows the views counted in the current period and the views the plan includes. The usage figures are estimates until the counting is confirmed. A figure that reads "Unaccounted" has no count behind it yet.

## What happens at a limit

A site with a spend budget set to stop at the limit serves a "temporarily unavailable" page once the budget is reached, until the cap is raised. A budget that only sends alerts never stops a site. Set the budget on the budget screen. The rules are in [spend budgets](/docs/guides/billing/budgets).

Charges for views beyond the included amount are covered in [overage](/docs/guides/billing/overage).
