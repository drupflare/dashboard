This page shows you how to connect a Git repository so a site can pull its code. It is for site owners and developers.

A repository connection gives your organization access to the repositories you pick on one Git provider. A site uses that connection to pull code from a repository. Connect the provider once, then attach repositories to sites as you need them.

## Connect GitHub

Open Integrations, then choose GitHub. GitHub opens its own page, where you pick the repositories to share with Drupflare. When GitHub returns you to the dashboard, the connection is listed.

Only GitHub connects from the dashboard today. The other providers, GitLab, Bitbucket, Gitea and Forgejo, show as coming soon on the Integrations page.

## Remove a connection

Revoke a connection from the Integrations page. Revoking a connection is a separate step from detaching a repository, which is not covered here.
