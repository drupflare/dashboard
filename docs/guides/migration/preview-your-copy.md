This page explains how to check the managed copy of an import before you decide what to do next. It is for owners reviewing an import.

A separate preview step for the copy is not available yet. The managed copy is the site that the import creates. Check it at its own address, then decide on a move. The move page shows when the new site matches the old one, and approving starts the switch.
