Drupflare runs Drupal sites on Cloudflare. Pick the path that matches your job.

If you run one site and want it live, read [what Drupflare is](/docs/start/what-is-drupflare), then [create your first site](/docs/start/create-your-first-site), then the [site guides](/docs/guides/sites/create-a-drupal-site).

If you write code for a site, start with [connect a repository](/docs/guides/code/connect-a-repository), then [environments](/docs/guides/environments/staging-and-previews) and the [API reference](/docs/reference/api/index).

If you manage several sites for clients, read [agency start](/docs/agencies/agency-start), then [teams](/docs/guides/teams/organizations).

If you run a department or a nonprofit site, read the [billing guides](/docs/guides/billing/plans), the [data guides](/docs/guides/data/backups), and [troubleshooting](/docs/troubleshooting/site-degraded).

If you are central IT or manage a large university estate, read the [institution pages](/docs/institutions/evaluate-drupflare), the [migration guides](/docs/guides/migration/overview), and [fleet rollouts](/docs/guides/upgrades/fleet-rollouts).

If you review security or buy the service, read the [security overview](/docs/security/overview) and the [security review packet](/docs/institutions/security-review-packet).

If you run your own server, read [self-hosted guides](/docs/guides/self-hosted/install-bastion) and [leaving Cloudflare](/docs/exit/leave-cloudflare).
