A pilot tests Drupflare with a few sites and a few departments, against criteria you agree before it starts.

The Pilots feature is on the institution starter and standard plans. Other plans do not show it.

## 1. Agree the criteria before you start

Write them down with the department owners. Examples: a site's hosting cost against the baseline (the starting number), the hours a team spends on updates, and the time to restore a backup. Include the cases where you expect the result to be bad.

## 2. Set up the pilot

Open the Pilots page and create a pilot. Add the sites and enter the baseline you measured before the pilot.

## 3. Record observations

Add an observation each time you measure. Keep the bad ones. A report that hides them is not useful to a reviewer.

## 4. Decide

Write the success line in your own words. The dashboard shows a template as help text only, and it does not save the template.

## 5. Print the report

Print the report from the browser, or export the observations as a CSV (a spreadsheet file). The report shows the Drupflare cost as not measured. Measure it yourself if you need it.
