Test Drupflare with a small set of your own sites before you commit an estate to it. Write your requirements first, then check each one against the product.

## Set up a trial

Create an account and try one site. The [free and paid comparison](/docs/start/free-vs-paid) shows what each tier includes. Plan prices come from your contract, not from this page.

## Check your requirements

Write each requirement as a test you can run. Examples:

- Can your people sign in through your identity provider? See [Central sign-in](/docs/institutions/central-sign-in).
- Can you see who changed what? Audit rows (log entries of each change) exist, but an organization-level audit page is not available yet.
- Where is data stored? See [Data location](/docs/institutions/data-location).
- Does the site meet your accessibility bar? See [Accessibility conformance](/docs/institutions/accessibility-conformance).

Record the result of each test, including the ones that fail.

## Run a pilot

When the basic tests pass, run a [pilot](/docs/institutions/pilot-playbook) with a few departments.
