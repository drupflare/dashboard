Use this page to find the material for a security review. Each item links to the page that holds it.

- [Security overview](/docs/security/overview): how accounts, sites and data are protected.
- [What we store](/docs/security/what-we-store): each kind of data and where it lives.
- [Data retention](/docs/security/data-retention): how long each kind is kept.
- [Credential handling](/docs/security/credential-handling): sessions, keys and what a site never holds.
- [Subprocessors](/docs/security/subprocessors): third parties that process data.
- [Data location](/docs/institutions/data-location): what location settings are set today.
- [Incident response](/docs/security/incident-response) and [Responsible disclosure](/docs/security/responsible-disclosure).
- [Compliance and regulated use](/docs/security/compliance-and-regulated-use): what is and is not in place.

The threat model is maintained with the security review. Ask for it directly.

These pages do not claim any certification. Ask Drupflare for the current position on any standard your review names.
