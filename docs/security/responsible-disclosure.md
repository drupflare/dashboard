Report a security problem by email to [support@drupflare.com](mailto:support@drupflare.com). Put "security" in the subject.

Include:

- What you found and where, such as a page, route or action.
- The steps to reproduce it.
- The effect you think it has.

A testing policy is not written yet. Ask before you test against a live customer site.

Drupflare has no published response time or reward program yet. Not available yet. Expect an acknowledgment, not a fix date.

For how Drupflare handles incidents after a report, see [Incident response](/docs/security/incident-response).
