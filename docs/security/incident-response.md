Drupflare does not publish an incident response commitment (a written promise about how it responds to incidents) yet. Not available yet.

What the product does today:

- Changes that matter for security write audit rows.
- Sensitive actions need a step-up check, and some can only be done from a signed-in session.
- Platform switches (admin on/off settings) can stop new rollouts and sign-ups.

Customer notice periods, the contact route during an incident, and the post-incident report are not written down. Ask for them in writing before you sign.

To report a problem, see [Responsible disclosure](/docs/security/responsible-disclosure).
