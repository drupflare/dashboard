There is no single export for a whole account yet. Not available yet.

Export each piece you need:

- **Site backups.** Open a backup on the site and download it as SQL (a database file format). See [Export your site](/docs/guides/sites/export-your-site).
- **Site code.** If you connected a repository, your code is there. Clone it (copy it to your computer) from the repository. See [Connect a repository](/docs/guides/code/connect-a-repository).
- **Usage and cost reports.** Export the cost-center report and the client usage as CSV. See [Cost centers and showback](/docs/guides/billing/cost-centers-and-showback).

Keep a copy of each file outside Drupflare. Check that each one opens before you close the account.
