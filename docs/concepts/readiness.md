Readiness tells you how far a site has come toward serving people. There are three levels, and each one needs every check in it to pass before the site reaches it.

- **Live** needs the site to respond.
- **Verified** needs admin access verified. It also needs a verified custom domain and verified HTTPS when the site's intended use needs a domain.
- **Production Ready** needs a backup restored in a test, a critical alert with a delivered test notification, and named technical, billing and recovery contacts.

The [first-day checklist](/docs/start/first-day-checklist) lists what each check asks of you.

## Checks are not stored

The dashboard works out readiness each time it reads the site. A level is not saved. A check that stops holding drops the level, and the site page lists the check as open again.

A check marked not checked has no result yet. It is not a failure.
