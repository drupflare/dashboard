**Do I need a Cloudflare account?**
Yes, for a self-managed site, which runs in your Cloudflare account. A managed site runs in Drupflare's account. See [choose a plane](/docs/start/choose-a-plane).

**What does Live mean?**
The site responds to a request. Verified and Production Ready add more checks. See the [first-day checklist](/docs/start/first-day-checklist).

**Can I undo a change?**
Code can go back to an earlier release. Your content and settings stay as they are. A restore point can bring back the database as it stood at a moment. See [roll back code](/docs/guides/code/roll-back-code) and [backups and recovery](/docs/concepts/backups-and-recovery).

**What happens to my site if I delete it?**
The site stops serving. Its address is held for 90 days, and its backups are kept. See [delete and restore](/docs/guides/sites/delete-and-restore).

**Can a self-managed site run as a managed site too?**
Yes. Adopting a site adds a managed copy and leaves the original as it was. See [adopt to managed](/docs/guides/self-managed/adopt-to-managed).

**Is there a command-line tool?**
Not in this release. Use the dashboard or the [API](/docs/reference/api/index).

**Where is my data kept?**
It depends on the plane. See [what runs where](/docs/concepts/what-runs-where) and [what we store](/docs/security/what-we-store).
