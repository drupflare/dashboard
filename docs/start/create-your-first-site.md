Open **Sites** and choose **Create a Site**. The wizard has two steps. Each step has a default, so you can skip either of them.

1. Pick a template. A template that is not ready yet is marked as coming soon and cannot be picked.
2. Name the site and create it.

The site opens with the progress screen, titled **Creating Your Site**. It finishes when every step succeeds, and then it shows **Your site is ready.** You can leave the page. The creation keeps running.

If the creation fails, the progress screen shows the failure. The site's activity keeps the record.
