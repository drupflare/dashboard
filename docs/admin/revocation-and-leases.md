A lease is a time-limited permission that lets a site keep running under its current authority. Revoking access and expiring leases from an admin screen is not available yet.

What an organization can do today:

- Revoke an API key. See [API keys](/docs/guides/teams/api-keys).
- Remove a site grant or a delegation. See [Site grants](/docs/guides/teams/site-grants).
- Revoke a self-hosted node. See [Unpair a node](/docs/guides/self-hosted/unpair).

For a site that must lose access now, record the request and escalate it. Do not wait for a screen that does not exist.
